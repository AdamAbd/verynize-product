## Arsitektur

- `integrations/codec-css.mjs`: ditambah `matchMedia(query, env)` — evaluator media query (daftar koma, `not`/`only`, tipe media, `and`/`or`, sintaks range `(400px <= width < 900px)`, `min-/max-`, `prefers-color-scheme`, `hover`, `pointer`, `orientation`, `prefers-reduced-motion`, rasio, resolusi). Default viewport 1440×900, terang, hover.
- `integrations/codec-css-cascade.mjs` (baru): parser stylesheet tanpa dependensi (aturan, `@media`, `@supports`, `@layer` blok dan pernyataan, `@import` dengan `layer()`/media, CSS nesting `&`), parser + matcher selector (type, class, id, atribut dengan semua operator dan flag `i`, kombinator `> + ~`, `:root`, `:first/last/only-child`, `:nth-*` termasuk `an+b`, `:*-of-type`, `:not/:is/:where/:has`, `:empty`, `:any-link`, `:checked`, `:disabled`, `:lang`, `:dir`; pseudo-class state dan pseudo-element tidak pernah cocok saat import), specificity, ekspansi shorthand ke longhand (margin/padding/inset logis, border dan sisinya, radius, outline, overflow, flex, flex-flow, place-*, background berlapis, font, text-decoration, transform → translate/rotate/scale), dan cascade (UA < layer author berurutan < author tanpa layer < inline; urutan layer dibalik untuk `!important`; lalu specificity, lalu urutan sumber).
- `integrations/codec-html.mjs` (baru): parser HTML toleran (elemen void, raw text, penutupan implisit `p/li/td…`, entitas, `<html>`/`<body>` implisit, SVG inline disimpan sebagai markup), pemuat sumber daya (`file:` di dalam folder halaman saja, `http(s)` hanya bila `allowRemote`, `data:`; batas per sumber daya 2 MB, total 12 MB, timeout 8 s, maks 48 stylesheet, kedalaman `@import` 8), stylesheet UA ringkas (margin `body`/`p`/heading, ukuran heading `em`, list, form control, tabel diaproksimasi sebagai flex), preflight Tailwind untuk halaman Tailwind (tag CDN, `<style type="text/tailwindcss">`, atau heuristik ≥60% class adalah utilitas), lalu per elemen: cascade, custom property terwarisi dengan resolusi `var()` di elemen yang mendeklarasikannya, keyword `inherit/initial/unset/revert`, unit relatif (`em`, `rem`, `%` line-height, `vw/vh/vmin/vmax`, `ch`) → px, `currentColor`. Hasilnya JSX dengan class arbitrary-property (`[padding-top:12px]`) atau class Tailwind asli halaman, lalu masuk ke `createArtboards` — engine Tailwind v4, pewarisan teks dan layout flow yang sama dengan jalur JSX. `background-image: url()` lokal menjadi paint gambar (`data-fills`), `<img>` lokal disematkan, `<img>` remote tetap URL absolut (diambil oleh pengambil aset yang sudah ada), `<svg>` inline menjadi gambar SVG tersanitasi.
- `integrations/codec-residual.mjs` (baru): kanal samping `data-vn='{…}'` untuk state yang tidak punya class. Setiap grup (bayangan, filter, mask, text range, binding) punya **tanda tangan visual**; saat parse, grup hanya dipulihkan bila class yang sudah diterapkan menghasilkan tampilan yang sama. Bila class diedit (oleh agen atau manusia), grup basi dibuang dan class menang, dengan peringatan. Juga: `locked`, `preview` artboard, nama dengan spasi tepi, properti dorman (kolom grid pada frame flex, arah pada frame non-flex, padding/gap pada frame bebas, `radius` lama di samping `cornerRadii`), dan geometri layer tersembunyi.
- `integrations/codec-source.mjs` (baru): `documentToJsx`/`jsxToDocument` (header `/* @verynize {…} */` membawa token, variabel bertipe, alias dan pengaturan halaman; juga membaca komponen React hasil `tailwindCode`) dan `documentToHtml`/`htmlToDocument`.
- `integrations/tailwind-engine.mjs`: hasil kompilasi varian kini memuat kondisi `@media`, deklarasinya, dan apakah selectornya "polos" (tanpa `:hover`, `.dark &`, dll.).
- `integrations/tailwind-map.mjs`: opsi `viewport` — varian responsif yang cocok diterapkan setelah class dasar; semua varian dicatat sebagai `variantClasses` (urutan sumber). Peringatan tetap memakai kata "is ignored" untuk varian yang tidak diterapkan (fixture 22 dan tes lama tidak dilonggarkan). `hidden` (display:none) tidak lagi menghapus class layout (`hidden md:flex` bekerja; varian yang menetapkan display memunculkan kembali).
- `integrations/jsx-codec.mjs`: serializer menulis `hidden`, `variantClasses`, `data-vn`, mode `full` (sumber gambar dan paint gambar tidak dielisi), dan key teks yang dideklarasikan sendiri (`styleOwn`) walau sama dengan nilai warisan.
- `integrations/export-html.mjs`: opsi `lossless` — `data-vn-node` (rekaman layer) + `data-vn-sig` (hash deklarasi). `integrations/export-code.mjs`: `cssCode(html, tokens, {document, pageId})` menambahkan atribut lossless per layer (dicocokkan lewat `data-id`) dan blok `verynize-meta`; `:root` kini memuat variabel bertipe dan alias (`var(--target)`); `tailwindCode` menambah header `@verynize` (komentar "Colour variables…" tetap pertama).
- Perubahan kecil di file bersama: `design-edit.mjs` (`variantClasses` di COMMON_KEYS, opsi `viewport` untuk `createArtboards`/`buildNodes`, pemanggilan `applyResidual` di build dan edit), `design-store.mjs` + `web/app.js` (validasi `variantClasses` sebagai string ≤ 4000), `design-cli.mjs` (perintah `import-html`, `import-jsx`, `export-jsx`, `export-css`; import HTML via CLI hanya membaca file di folder halaman), `package.json` (`eval:import`).

## Round trip dan cakupan

- `codec-roundtrip.test.mjs` membangun "kitchen sink" lewat codec, lalu memberi setiap properti yang bisa diatur inspector secara langsung (bayangan box/inner/drop/text dengan variabel dan entri tersembunyi, filter layer/backdrop/tersembunyi, mask tersembunyi, paint stack solid/gradien/gambar, SVG paints dan warna SVG terikat, warna shader dan slider, binding Dimension/Number/Font family/Font weight dan alias, text range tumpang tindih, `locked`, `hidden`, preview, flip, `cornerRadii`, `strokeWidths`, border/outline terikat variabel, `variantClasses`, nama ber-spasi, properti dorman). Lalu dokumen → JSX → dokumen dan dokumen → HTML/CSS → dokumen dibandingkan per layer (modulo id) — keduanya identik, dan JSX adalah titik tetap.
- Tes cakupan meng-enumerasi skema dari teks `validate()` (`web/app.js`), `validateDocument` (`design-store.mjs`), `validateEffects`/`paintError` (`web/node-style.js`), `validate` shader (`web/shaders.js`), `defaults`/`NODE_DEFAULTS`, dan komentar model node codec di `design-edit.mjs`. Properti yang tidak dipakai kitchen sink membuat tes gagal (hanya `id`, `parentId`, `type`, `shortId`, `measured` dikecualikan). Selama sesi ini agen inspector menambah `strokeToken`, `strokeColors` dan `outlineToken`; tes menangkapnya dan agen itu memperluas kitchen sink + codec — mekanismenya terbukti bekerja.
- `effects.test.mjs`: tes lama mengharapkan bayangan box kembali sebagai string `shadow`. Asersi aslinya dipertahankan untuk jalur class saja (kode tanpa `data-vn`, seperti yang mungkin ditulis agen) dan ditambah asersi yang lebih ketat: dengan `data-vn`, `shadows`/`filters` kembali persis. Tidak ada asersi yang dilonggarkan.

## Batas (jujur)

- Importer baru belum dipasang ke dialog "Import HTML" aplikasi (`web/app.js` masih memakai importer lama di renderer, kecuali jalur metadata JSON yang memang lossless) maupun ke tool MCP (`design-tools.mjs` sedang disunting agen lain). Tersedia lewat `integrations/codec-html.mjs` (`importHtml`, `importHtmlFrom`) dan CLI.
- Tidak menjalankan JavaScript halaman; konten yang dibangun oleh script tidak terlihat. `::before/::after`, `@font-face`, `@container`, `float`, `position: relative` dengan offset, `background-size/position`, padding persentase dan family font per text range tidak direpresentasikan (dihitung dan dilaporkan sebagai peringatan). Containing block absolut selalu parent langsung; tabel diaproksimasi sebagai flex.
- Remote opt-in tanpa cookie/autentikasi; redirect diikuti oleh `fetch`. Batas memakai nilai default di atas, bisa diubah per panggilan.
- Identitas HTML/CSS untuk export Verynize memakai rekaman layer yang ditandatangani: selama deklarasi CSS sebuah layer tidak berubah, layer dipulihkan persis; setelah diedit, layer itu dibangun ulang dari CSS (jalur umum, aproksimatif) dan layer lain tetap persis.
- "Identitas modulo id" berlaku untuk dokumen yang geometrinya berasal dari layout headless (seperti hasil codec). Ukuran hug yang diukur oleh kanvas asli (`measured: true`) dihitung ulang dengan estimasi teks setelah round trip. Export komponen Tailwind sengaja membuang posisi artboard di kanvas.
- Varian responsif yang diterapkan pada satu viewport menggantikan nilai dasar di layer; class varian tetap tercatat dan ditulis balik, tetapi nilai dasar yang tertimpa tidak disimpan.

## Tindak lanjut: importer dipasang ke produk (30 Oktober 2026)

Batas "belum dipasang ke dialog dan MCP" di atas kini tertutup.

- **Dialog "Import HTML" di aplikasi desktop.** Modul baru `desktop/html-import.cjs` menyediakan IPC `importHtml` (HTML tempel) dan `importHtmlFile` (dialog buka file asli; stylesheet `<link>`/`@import` dan gambar di-resolve relatif ke file, hanya di dalam foldernya; http(s) hanya bila "Load remote stylesheets" dicentang). Didaftarkan dengan satu baris di `desktop/main.cjs`, diekspos di `desktop/preload.cjs`, dan didokumentasikan di `desktop/README.md`. `web/html-import.js` (script baru setelah `figma-panel.js` di `web/index.html`) menambahkan pemilih viewport (1440/1280/768/390), kotak centang remote dan tombol "Choose HTML file…" ke dialog, lalu mengganti handler `#apply` saat bridge desktop tersedia (build browser tetap memakai importer lama). Hasilnya dimuat dengan `loadDocument` (satu langkah undo), artboard baru diseleksi (`window.design.setSelection`, tambahan kecil di `web/app.js`), dan catatan importer ditampilkan sebentar di `#import-notice`. Import ke dokumen yang ada menaruh artboard di sebelah kanan artboard lain dan tidak mengikat ulang token yang namanya bertabrakan dengan nilai berbeda.
- **Mode fragmen.** HTML tempel tanpa `<html>/<head>/<body>` tidak dibungkus artboard viewport: setiap elemen tingkat atas menjadi artboard (posisi absolut px → posisi kanvas), dengan aturan `<style>` dan pewarisan dari `<html>/<body>` implisit. Ini mempertahankan perilaku tes "inert import" lama di `tests/canvas.cjs` (satu layer, terseleksi, script tidak dijalankan); tes itu hanya ditambah penantian dialog tertutup karena import kini asinkron — asersinya tidak diubah.
- **Tool MCP** (satu definisi untuk server stdio dan bridge desktop): `import_html` (`html`, `path` absolut, atau `url` dengan `allowRemote`; `viewport`), `import_jsx` (output `export_jsx`, komponen React Code export, atau JSX `create_artboard`; banyak root), `export_css`, `export_jsx`. Import HTML berjalan dua tahap (`prepareHtmlImport` di `codec-source.mjs`): stylesheet dan cascade dihitung di luar transaksi dokumen, lalu hasilnya diterapkan pada revisi terkini. Daftar tool di `integrations/mcp.test.mjs` diperbarui dengan empat nama baru.
- **Export komponen Tailwind kini lossless.** `tailwindCode` menyimpan posisi kanvas artboard sebagai `data-canvas-x/y` (inert di React; `data-component-*` tetap tidak muncul sesuai asersi lama), dan `jsxBody` membacanya kembali. Tes round trip kini membandingkan semua properti termasuk x/y artboard (lebih ketat; filter pengecualian sebelumnya dihapus).
- **Celah identitas yang ditemukan tes baru dan diperbaiki:** margin nol eksplisit kini ditulis `m-0`; ukuran font yang dideklarasikan tanpa leading sendiri tidak lagi memakai kelas bernama yang membawa leading implisit (mis. `text-2xl`).
